# チェックシート編集

組立チェックシート（Excel）をスマホ・タブレット・PCで編集するツールです。

- 公開URL：https://tomokisan0127-png.github.io/checksheet/
- できること：項目の追加・変更・並べ替え、ページの追加・削除、文書番号と改訂履歴の自動更新、文章・内容チェック（自動・AI）、他機種との比較、印刷イメージのプレビュー
- Excelファイルは端末の中だけで処理し、どこにも送りません
- ホーム画面に追加でき、一度開けば電波がなくても使えます

## 更新するとき

`index.html` を新しいものに差し替えるだけです。使う人の端末では、次に電波のある所で開いたときに新しい版になります。
